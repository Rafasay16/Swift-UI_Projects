# 🚚 HackaTruck - Projetos em Swift e SwiftUI

Este repositório reúne os arquivos e projetos desenvolvidos durante minha participação no HackaTruck MakerSpace, programa educacional focado no desenvolvimento de aplicações iOS utilizando Swift e SwiftUI.

Durante o programa, tive a oportunidade de aprender e aplicar conceitos modernos de desenvolvimento para o ecossistema Apple, criando interfaces, explorando componentes nativos e desenvolvendo aplicações utilizando boas práticas de programação.

📚 Sobre o HackaTruck

O HackaTruck MakerSpace é um projeto educacional itinerante que percorre universidades brasileiras promovendo capacitação em tecnologias como:

Swift

SwiftUI

Desenvolvimento de aplicativos iOS

Cloud e APIs

Pensamento computacional

Inovação e desenvolvimento de soluções digitais

O programa incentiva a prática e o aprendizado através da criação de projetos e desafios durante as atividades.

🧑‍💻 Tecnologias utilizadas

Swift

SwiftUI

Xcode

iOS Development

📂 Estrutura do repositório

Neste repositório estão incluídos:

Exercícios realizados durante as aulas

Projetos desenvolvidos durante os desafios

Exemplos de interfaces utilizando SwiftUI

Arquivos de estudo e prática

🎯 Objetivo

O objetivo deste repositório é registrar minha evolução e aprendizado durante o HackaTruck, além de servir como portfólio dos projetos desenvolvidos utilizando Swift e SwiftUI.
